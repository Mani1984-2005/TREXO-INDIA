# ML Architecture
> Generated by `scripts/ml_generate_docs.py` from the actual result files in `reports/ml/` and `models/`. Nothing here is hand-typed from memory.

```
raw xlsx (read-only) -> data_pipeline -> valid_sales_v1.csv.gz (+ exclusion log, manifest)
   -> features (cutoff-safe product features) -> labels (future-window only)
   -> validation.splits (chronological, purged)
   -> dead_stock: calibration (isotonic recency rule) / classifier (Module A) / model (Module B, challengers)
   -> forecasting: engine / predict (Module C)      -> movement (Module D)
   -> reorder.policy (E)  -> recommendations (F)   -> anomaly (G)  -> financial (H)
   -> decision_engine (I) -> inference.service     -> registry (versioned, checksummed artifacts)
```
Package: `src/trexo/ml/{data_pipeline,features,validation,dead_stock,forecasting,movement,reorder,recommendations,anomaly,financial,decision_engine,evaluation,simulation,explainability,registry,inference}`. Scripts in `scripts/ml_*.py`; tests in `tests/ml/`.

## Design decisions
| Decision | Reason |
|---|---|
| **D01 bad-debt group excluded by invoice, first rule** | approved governance decision; whole financial event, not StockCode B, must never enter demand analytics |
| Deployed dead-stock predictor = **calibrated recency rule**, ML models kept as rejected challengers | ML did not beat it (see `MODEL_EVALUATION_REPORT.md`); transparent beats complex when no gain |
| Chronological purged splits, cutoffs every 30 days | no temporal leakage; label windows close before the next split's cutoff (asserted in code) |
| Target = no valid sale in next 60 days | no stock data exists; physical dead stock cannot be a target |
| Classes via calibrated probability bands (0.2/0.4/0.6/0.8) | interpretable: "% of look-alike products with no sale in 60 days"; validated out-of-time |
| 'Confirmed Dead Stock' only with `on_hand_qty > 0` AND critical evidence AND non-LOW evidence quality | never from sales alone |
| Forecast method chosen per demand class (Syntetos-Boylan) from backtest MAE | different classes have different best methods |
| Registry with SHA-256 checksums and round-trip load before marking `TRAINED_AND_VERIFIED` | artifacts cannot be silently corrupted |
| Priority = risk x value weight x evidence weight (documented table) | no opaque score |

## Interfaces
`trexo.ml.inference.service.InferenceService` methods: `dead_stock_detection`, `dead_stock_risk_prediction`, `demand_forecast`, `movement_classification`, `reorder_recommendation`, `anomaly_detection`, `reduction_actions`, `management_summary`. Raises `InvalidRequestError` for bad input and `ModelUnavailableError` if artifacts are absent (never returns a fabricated prediction).
