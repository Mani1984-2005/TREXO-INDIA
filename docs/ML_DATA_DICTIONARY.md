## Valid-sale rule (first-match exclusion)
**D01_BAD_DEBT_GROUP (invoices A563185/A563186/A563187)** > MISSING_DATE > MISSING_QUANTITY_OR_PRICE > NON_PRODUCT_CODE (POST, DOT, C2, BANK CHARGES, AMAZONFEE, CRUK, B, D, M, m, S, PADS, GIFT_*, DCGS*) > CANCELLATION_INVOICE (`C`) > NON_POSITIVE_QUANTITY > NEGATIVE_PRICE > ZERO_PRICE. Reconciles to 541,909 rows. StockCode `B` remains a defensive non-product code only because every `B` row in this dataset belongs to D01; D01 is matched first and is the governed reason.

|---|---|

| `intervention`, `reason_for_recommendation`, `expected_impact_direction`, `inventory_value_impact`, `requires_human_approval` | full recommendation contract; no action is executed automatically |
