## Run predictions
```python
from trexo.ml.inference.service import InferenceService
svc = InferenceService()
svc.dead_stock_detection({"product_id": "22783", "as_of": "2011-12-09",
    "sales_history": [{"date": "2011-06-01", "quantity": 5, "unit_price": 2.1, "invoice_no": "5001"}], "on_hand_qty": None})
svc.demand_forecast(req, horizon_weeks=4); svc.reorder_recommendation({**req, "on_hand_qty": 40, "lead_time_days": 14})
svc.reduction_actions(req); svc.movement_classification(req); svc.anomaly_detection(req); svc.management_summary()
```
Responses carry product id, model version, timestamp, prediction, classification, metrics, explanation, action, confidence/evidence quality and missing-input warnings. Invalid input raises `InvalidRequestError`; absent artifacts raise `ModelUnavailableError`.
