# Feedback and Learning
> Generated by `scripts/retail_generate_docs.py` from actual result files in `reports/ml/retail/` and `models/`.

`feedback/store.py` (SQLite). Tables: recommendations (prediction, risk, suggested offer, predicted units/profit), approvals (accountable approver, decision, approved offer), executions (actual offer, window, experiment arm), outcomes (units, actual price, gross profit, remaining inventory, customer response, verified flag).

Enforced and tested: an execution cannot be logged for an offer that was not approved; an approver is mandatory; negative outcomes rejected; prediction-vs-actual metrics (units MAE/bias, gross-profit MAE) only from verified outcomes.

**Controlled experiments:** deterministic hash randomisation (reproducible, auditable), bootstrap CI on the treatment-control difference, refusal to conclude with < 20 units per arm.

**Retraining gate:** `retraining_gate` returns `promote=True` only if >= 200 verified outcomes, the candidate beats the incumbent by the required margin and a human approval flag is set; even then nothing is swapped automatically (a person deploys). Models in `models/` are never overwritten - every training creates a new versioned directory and updates `LATEST` only after verification.

Not yet exercised: no real outcomes exist, so the loop is tested with synthetic records only.
